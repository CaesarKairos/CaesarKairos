LANDING PAGE DE PORTFÓLIO — PROMPT DE DESIGN

OBJETIVO
Criar uma landing page de portfólio pessoal para desenvolvedor Full Stack, voltada para recrutadores. O visual deve ser profissional, pessoal e memorável — moderno, limpo e acolhedor, sem elementos brutalistas, sem tipografia caótica ou colagem visual. Transmitir personalidade, organização e confiança.

IDENTIDADE VISUAL
- Paleta de cores (usar exatamente estes tons):
  • Fundo principal / creme: White #FAF9F6
  • Destaque claro / badges: Leaf #ECF39E
  • Acento secundário: Moss #90A955
  • Cor principal de ação (botões, links, ícones): Grass #40916C
  • Cor de contraste escura (títulos, footer, textos de destaque): Forest #31572C
- Tipografia: usar um pareamento de duas fontes — uma fonte de título com peso forte e personalidade (mas elegante, não agressiva nem "grunge"), e uma fonte de corpo limpa e legível (estilo geométrico/humanista, ex. Inter, General Sans ou similar). A palavra "Portfólio" deve ter destaque tipográfico marcante, mas sóbrio — inspire-se na lógica de composição das referências (título grande ao lado da imagem), sem copiar o estilo ilustrado/urbano delas.
- Estilo geral: espaçamento generoso, cantos arredondados, sombras suaves, ícones simples de linha, sensação "aconchegante" (não corporativa fria, não neon).

ESTRUTURA DA PÁGINA

1) HERO SECTION
- Coluna esquerda: imagem/foto em formato placeholder (retângulo ou moldura arredondada com leve borda nos tons verdes), pronta para ser substituída depois.
- Coluna direita:
  • Título "Portfólio" em destaque tipográfico
  • Abaixo, um "about me" curto e direto (2–3 linhas), focado no que um recrutador precisa saber: "Cesar Batista (Caesar Kairos) — estudante de Desenvolvimento de Sistemas e desenvolvedor Full Stack, com experiência em frontend, backend, APIs, bancos de dados e integração entre serviços e tecnologias."
  • Lista de tecnologias organizada por categoria, em formato de tags/badges usando as cores da paleta:
     - Frontend: HTML, CSS, JavaScript, React, Next.js, Tailwind CSS
     - Backend: Node.js, Express, APIs REST, autenticação, desenvolvimento de serviços web
     - Database: MongoDB, bancos relacionais (SQL), modelagem e integração de dados
     - Tools: Git, GitHub, Postman, Figma, ambientes de desenvolvimento
     - AI: integração com APIs de IA (OpenAI/OpenRouter), engenharia de prompts, sistemas de recomendação e automação inteligente
  • Links de contato e redes sociais visíveis (ícones: GitHub, LinkedIn, E-mail — usar placeholders [GitHub] [LinkedIn] [E-mail])
- Canto superior direito: navegação rápida (Sobre / Projetos / Skills / Artigos / Contato) + botão/link de contato em destaque.

2) ABOUT ME (seção longa, separada da hero)
Espaço para uma narrativa mais completa, organizada em blocos de leitura curtos (pode usar subtítulos como "Trajetória", "O que me move", "Fora do código"). Conteúdo a adaptar:
- Trajetória: interesse por programação nasceu de vídeos na internet; hoje é estudante de Desenvolvimento de Sistemas e dev Full Stack, movido pelo prazer de transformar ideias em algo que funciona de verdade.
- O que me move: apesar de atuar em exatas, se considera profundamente ligado às humanas — escreve livros e histórias, tem interesse por psicologia, arte, cinema, literatura e mitologia. Acredita que tecnologia deve ser acessível não só no uso, mas no conhecimento para compreendê-la.
- Fora do código: gosta de cinema (principalmente filmes despercebidos), jogos 2D como OneShot e Minecraft, ama a cor verde e aliens estereotipados do cinema como exemplo de como a arte molda a percepção coletiva.
- Visão de futuro: quer ser alguém a quem outras pessoas recorrem, ajudando quem está começando em desenvolvimento, escrita ou arte — quer compartilhar conhecimento, não só acumulá-lo.

3) PROJETOS (grid de até 4 cards; preencher com 2 no momento)
Cada card deve ter: título, descrição curta, tags de stack, botão principal "Saiba mais" (leva a uma página de detalhes do projeto) e um link/tag secundário para o repositório no GitHub.
- Card 1 — BIBI (Biblioteca Inteligente): sistema feito para facilitar o gerenciamento de bibliotecas escolares.
- Card 2 — Moovibe: plataforma com IA que recomenda um filme a partir de uma música, cruzando letras, contexto cultural e dados do filme para encontrar a mesma "vibe".
- Deixar 2 slots adicionais no layout preparados para novos projetos futuros (podem ficar como placeholder ou ocultos).

4) SKILLS
Seção separada dos projetos, organizada em 4 blocos/colunas ou tabs: Cursos, Ferramentas, Tecnologias, Soft Skills. Usar tags/pills com as cores da paleta para leitura rápida.

5) ARTIGOS
Seção com cards de artigos escritos, cada um levando (link externo, nova aba) para uma página como Substack. Deixar claro visualmente que é conteúdo externo (ex. ícone de link externo).

6) FOOTER / ENCERRAMENTO
Estrutura padrão de fechamento de portfólio: chamada para ação convidando para contato, repetição dos links de contato/redes sociais, e crédito/rodapé final.

LIBERDADE CRIATIVA
Sinta-se livre para sugerir seções adicionais coerentes com esse perfil (ex. linha do tempo, "now", depoimentos), desde que mantenham a mesma paleta, tom acolhedor e estrutura elegante.

REQUISITOS TÉCNICOS
- Design responsivo (mobile-first)
- Contraste de texto acessível sobre os tons de verde
- Estados de hover visíveis em botões, cards e links de navegação
